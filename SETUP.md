# Putting this on your profile (3 minutes)
github.com/UniosTimetabling shows the README.md of the repo UniosTimetabling/UniosTimetabling (it must be Public).
1. Open github.com/UniosTimetabling/UniosTimetabling and click "uploading an existing file".
2. Unzip this package. Drag in README.md, LICENSE and the assets folder. Commit.
3. Visit github.com/UniosTimetabling. The page now shows at the top of your profile.
4. Settings > Public profile: add a picture, Name, Bio, Email and location. Use the logo as the picture.
If UniosTimetabling is an Organisation, not a personal account: create a public repo named ".github", add a folder "profile" with the README.md from the .github/profile folder here, and also upload the assets folder to the UniosTimetabling repo.
